# Draft Requirements

Use `draft_requirement` for requirement requests. It researches the selected application source and returns a reviewable draft grounded in actual behavior.

Keep requirements observable and testable. If the source cannot establish a behavior, preserve that uncertainty for review instead of inventing an acceptance criterion.

Do not create test cases, scripts, runs, or live-test scopes unless the user separately asks for them.
